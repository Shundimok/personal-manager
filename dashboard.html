Ingegeven verlofdagen

Basisuurloon = je exacte bruto uurloon (€36,6258/u, "plat", zonder shiftpremie), toegepast op 8u per effectief gewerkte of verlofdag. Shiftpremie is bovenop, per shift/verlofdag variabel. Belangrijk: basisloon van deze maand wordt op tijd uitbetaald, shiftpremie die je uitbetaald krijgt is die van vorige maand. Je echte loonbrief gebruikt een fijnmaziger tier-systeem dat dit tool niet exact kan nabouwen — beschouw dit als een goede benadering, geen kopie.

Behouden shiftpremie tijdens verlof (%)

Shiftpremie = premie% × 8u × uurloon. KF geeft dezelfde premie als de dag waarop je die inplant (100%). PO behoudt 23,39% van die premie. IU en JV geven geen shiftpremie. GK behoudt 100%. Nettoschatting = RSZ (13,07%) + progressieve belastingschijven (25/40/45/50%, belastingvrije som €11.180) + gemeentelijke opcentiemen — dus wél rekening houdend met hogere schijven bij hoger loon, maar nog steeds een benadering zonder je persoonlijke situatie (kinderen ten laste, andere inkomsten, ...). Vereenvoudiging t.o.v. je echte loonbrief (die ook reistijd, opkomst-reserve, en het volledige herberekeningsmechanisme bevat) — bedoeld als inzicht, niet als volledige loonberekening.

Instellingen & data

Al je taken, notities, uitgaven en verkooplog worden lokaal opgeslagen in deze browser (localStorage) — er wordt niets naar een server verstuurd. Let op: dit betekent ook dat een andere pc/browser deze data niet automatisch ziet. Exporteer op pc A en importeer op pc B om gegevens over te zetten.

AI-assistent (optioneel)

Voor échte AI-antwoorden op het dashboard heb je je eigen Anthropic API-key nodig (aan te maken op console.anthropic.com). Met een key ingesteld kan je bovenaan ook gewoon typen "zet in mijn agenda dat ..." — de AI herkent afspraken/taken/vluchten en zet ze automatisch in je Taken. Zonder key werkt alleen de simpele, vaste zin "zet taak [omschrijving] erin" lokaal, zonder AI. Je key blijft alleen lokaal op je eigen pc opgeslagen en wordt rechtstreeks vanuit je browser naar Anthropic gestuurd — nergens anders.

Woon-werkverkeer (optioneel)

Voor live verkeersinfo heb je een gratis TomTom API-key nodig (developer.tomtom.com, geen creditcard vereist). Ook lokaal opgeslagen, nergens anders naartoe gestuurd.

Synchroniseren tussen pc's/toestellen (optioneel)

Vul dit in op élk toestel/browser met dezelfde 2 waarden, en je taken, recepten, uitgaven enz. blijven overal gelijk. Gratis, via je eigen Firebase-project (console.firebase.google.com → project aanmaken → "Firestore Database" → "Create database" → kies "Start in test mode"). Kopieer dan je Project ID (bij ⚙️ Project settings). Verzin zelf een unieke, moeilijk te raden Sync-ID (bv. een lange willekeurige code) — iedereen die deze 2 waarden kent kan bij je data, dus behandel ze als een wachtwoord.
